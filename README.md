# Snoekie-stats

Webapp (PWA) om verkeersongevallen en -inbreuken vast te leggen: foto's per partij, fotodossier (PDF), samenvatting van de documenten en verzending naar de werkmailbox.

Alles draait lokaal in de browser. Foto's en gegevens blijven op het toestel tot ze verstuurd worden; er staan geen persoonsgegevens in deze repository.
